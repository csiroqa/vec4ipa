## 1. 动机与目标

### 1.1 从物理推导（完整论证见 §1.2）

语音产生 = 气流源 → 声源 → 声道管 → 辐射。三段各自的独立物理自由度：

- **声道管**（面积函数 A(x)）：主收缩位置、次收缩位置、收缩宽度、唇端闭合、唇圆展、
  软腭旁路、咽腔宽度、舌尖姿态、侧向旁路 —— 9 个自由度
- **声源**：声带振动、声门开合、声门张力、湍流聚焦 —— 4 个自由度
- **气流**：气流方向 —— 1 个自由度（机制类别作 metadata）
- **时序**：段时长 —— 1 个自由度（除阻/段内时序走修饰符规则）
- **声道长度**：喉位高低 —— 1 个自由度（F4 及全谱缩放，唯一未映射的声学参数）

合计 **16 维**。每个轴满足三判据：(a) 声学可测量；(b) 有真实最小对立对；
(c) 与其他轴物理独立。

### 1.3 v8 的结构性问题（v0.1 诊断，仍成立）

1. **部位编码跨轴且权重悬殊**（tip_pos 1.1 vs body_pos 2.7），部位链步距
   12.5× 不均（ɸ→f 0.861 … ʃ→ɕ 0.247 … ʜ→h 3.082）；
2. **龈齶编码缺陷**（ɕʑ 的 body_pos=0 与 ʃ 相同）；
3. **协同发音坍缩**：ɧ/tʲ/kʷ 双收缩无法用器官划分的 tip_pos/body_pos 表达；
4. **喉部单轴化错误**（v0.1 曾并 cg+sg+tension → glottal_state，韩语 k͈/k/k͉ 无法分离，
   v0.2 恢复 tension 正交轴）；
5. **F4 无映射**（v0.3 补 larynx_height）。

**目标（用户需求）：**

- 双脣→脣齒→齒→齒齦→齦後→齦齶→捲舌→硬齶→軟齶→小舌→咽→會厭→喉，全链擦音
  **平等而准确**地支持；
- 肺部气流方式（鼻/爆/塞擦/擦/近/顫/閃/邊擦/邊近/邊閃）、协同调音（ɕʑ ɧ ʍ w ɥ ɫ
  k͡p ɡ͡b ŋ͡m）、非肺气流（喌/内爆/喷）不受影响；
- 音节性、送气、除阻、发声态、调音、协同调音、长短等修饰符全部平等支持；
- **共鸣腔显式化**：口腔腔 / 鼻腔腔 / 咽喉腔 各自为独立维度；
- **分布合理**：部位步距均匀、无近碰撞、混淆拟合与往返重建不劣化；
- **锚点全部数据派生**（声学测量优先，生理作参考）；**分类特征不造数值轴**。

## 3. 等距部位轴 `place`（核心设计）

**坐标域 [0.08, 0.92]（非 [0,1]）——为协同发音留余量。**
`place` 是参照锚点系统而非生理极限：协同发音（腭化 /t/→[tʲ]、软腭音前移 /k/→[k̟]、
圆唇化、卷舌扩散等）使音位实现越过相邻锚点最多约 1 个部位格（1/12）。
若锚点铺满 [0,1]，越界偏移无处编码，音位在协同发音下坍缩回锚点。故两侧各留
**1 格余量（margin = 1/12 ≈ 0.0833）**，锚点占 [0.08, 0.92]，步距恒为
**0.84/12 = 0.07**，协同发音偏移 ±1 格仍落于 [0,1] 界内。其余各轴
（glottal_state ±1、vel_open 0/1、lips_closed 0/1、area 0/1）是生理极限，
无需余量。修饰符协同发音规则（ʲ/ʷ/ˠ/ˤ 等）一律在锚点值上**叠加偏移**
（±0.04~0.07），不覆盖。

13 锚点，步距恒为 **0.07**，任意相邻部位对的距离贡献恒为
`w_place × 0.07²` —— 从构造上保证"平等支持"，不再依赖拟合碰运气。

**设计决定：**

- **元音前后度复用 `place` 轴**（三等锚点）：前 = 0.570（与 ç 同区），央 = 0.500，
  后 = 0.640（与 x 同区）；具体锚点由声学数据派生（`vowel_3d_anchors.json`，
  L&M 1996 + phonTools 九语料）。元音与同位辅音的区分靠 `effective_oral_area` +
  `duration`。圆唇元音（y ø œ 等）与不圆唇对共享 place/area，差异全在
  `lips_rounded`（IPA 图同一格只差圆唇——位置继承规则）。
- **双重收缩段（协同调音）用 `body` 轴**（不再取中间值——那是伪造中点）：
  - `ɧ`（齦後-齶）：place 0.360（主收缩龈後）+ body +0.4（次收缩硬腭）；
    与 ʃ（body 0）靠 body 轴分离 ✓
  - `tʲ`：place 0.290 + body +0.4；与 t（body 0）分离 ✓
  - `kʷ`：place 0.640 + lips_rounded 1.0（唇侧由圆唇轴承载）
  - `k͡p`：place 0.640 + lips_closed 1.0
  - `ɥ`：place 0.570 + lips_rounded 1.0
  - `w/ʍ`：place 0.640 + lips_rounded 1.0
  - 喌：front place（ʘ 0.080, ǀ/ǁ 0.290, ǃ 0.360, ǂ 0.570）+ body −0.4（软腭次收缩）
    + airflow −1.0 及 λ 联合区分
- **唇齿 f/v 不再需要 lips_closed=1.0**（v8 中用它强行区分双脣擦音与脣齒擦音，
  是本方案消除的语义混用）：`lips_closed` 收窄为"双脣闭合"，ɸβ 取 0.3（近闭），
  f v 取 0.0。

## 4. 喉部双轴：`voiced` + `glottal_aperture` × `glottal_tension`

喉部是**两个正交子系统**（不是一维）：声带开合（水平外展）与声带张力（纵向）
互相独立。v8 的 cg/sg 是 aperture 的两端（合并正确——METRIC.md 证实共线）；
`laryngeal_tension` 是独立的 tension 轴（v0.1 曾错误并入单轴，韩语 k͈/k/k͉
无法分离，v0.2 恢复）。

### `glottal_aperture`（开合，+ 外展 / − 收窄）

| 值 | 含义 | v8 对应（cg, sg） |
|----|------|------------------|
| +1.0 | 最大外展 /h/ | (0, 1.0) |
| +0.9 | 清送气 pʰ | (0, 0.9) |
| +0.7 | 浊送气 bʱ | (0.2, 0.7) |
| +0.55 | 气化/弛化 a̤ ɦ | (0.2, 0.55) |
| +0.4 | 清不送气 p s | (0, 0.4) |
| 0.0 | 常态（浊段默认） b d a | (0.2, 0) |
| −0.55 | 内爆收窄 ɓ ɗ | (0.55, 0) |
| −0.7 | 嘎裂 a̰ | (0.7, 0) |
| −1.0 | 全闭：/ʔ/、喷音持阻 pʼ | (1.0, 0) |

### `glottal_tension`（张力，slack ↔ stiff）——与 aperture 正交

| 值 | 含义 | 音系证据 |
|----|------|---------|
| +1.0 | stiff（紧张） | **韩语紧音 k͈**（phoible: sg− cg− fortis+，aperture 与 k 相同，仅张力不同） |
| +0.7 | 嘎裂伴随张力 | a̰（v8 tension +0.7） |
| 0.0 | modal | 大部分音 |
| −0.5 | slack（松弛） | **韩语松音 k͉**（lenis）、印地语 slack 浊音 |
| −0.6 | 气化伴随松弛 | a̤（v8 tension −0.6） |

**决定性证据（韩语 k 系列四向）**：
```
k   : aperture +0.4,  tension 0    ← 清不送气
kʰ  : aperture +0.9,  tension 0    ← 送气
k͈  : aperture +0.4,  tension +1   ← 紧音（fortis）
k͉  : aperture +0.4,  tension −0.5 ← 松音（lenis）
```
k/k͈/k͉ 三者 aperture 相同，**只有 tension 分离**——单轴必然坍缩（phoible 实证：
fortis 46 行全部 sg− cg−，与对应非紧音特征完全一致）。

### `larynx_height`（喉位/声道长度）

| 值 | 含义 | 音系证据 |
|----|------|---------|
| +1.0 | 喉上抬 | 挤喉持阻伴随（缩短声道 → 全谱上移） |
| 0.0 | 中性 | 大部分音 |
| −1.0 | 喉下移 | 内爆伴随（延长声道 → 全谱下移） |

**物理依据**：声道长度 L 是独立参数，F ∝ 1/L——**F4 及以上共振峰及全谱整体
缩放**是唯一未被其他轴覆盖的声学参数（声学参数核对表 §1.2）。独立对立罕见但
存在（喉位高低对立语言；临床音系学）。

## 7. "分布合理"验证标准（实施时执行）

| # | 检查 | 标准 | 工具 |
|---|------|------|------|
| 1 | 部位链 12 步等距 | 拟合后步距 CV ≤ 15% | `tools/check_place_chain.py` |
| 2 | 全表最近邻下限 | min NN ≥ 0.35（v8 为 0.215） | 同上 |
| 3 | 方式链步距 | 以 d 为基准的 9 种方式步距 CV ≤ 30% | 同上 |

| 5 | 132 段往返重建 | 每维误差 ≤ 0.02（现状水平） | `tools/test_suite.py` |
| 6 | 修饰符重建 | 全修饰符测试通过（现状水平） | `tools/test_suite.py` |
| 7 | 韩语 k/kʰ/k͈/k͉ 四向 | 四者两两距离 ≥ 0.35 | `tools/fit_distribution.py` 扩展 |
| 8 | 协同发音段 | ɧ 与 ʃ、ç 两两距离 ≥ 0.35 | 同上 |

## 9. 风险与取舍

- **元音前后度粒度**：单轴三等锚点（前/央/后 + 中间值）比 v8 连续轴略粗；
  若需更细可加半档（前偏央 / 央偏后），不破坏等距性。
- **双重收缩段**：k͡p 类取"后收缩部位"，与真正的单收缩软腭音 k 仅差
  `lips_closed` —— 距离由拟合权重保证（预期 ≥ 1.0）。
- **喉部合并的信息损失**：理论上是"可识别参数的合并"，但 `laryngeal_tension`
  在挤喉/嘎裂上的 EMG 独立证据被并入 `glottal_state` 收窄档；如需保留可在
  文档中注明该轴为 EMG 记录值而非知觉量。
- **破坏性变更**：所有二进制（ipa2vec.exe 等）、C 头、UI 与测试均需同步，
  `metric.json` 版本号 9 → 10，向量格式不可与 v8 混用。

## 10. 与 v8 完整对比（16 维 ↔ 16 维）

### 10.1 维度映射

| 0 | lips_closed | lips_closed | 保留 |

### 10.2 净变化

```
v8  16 维 ─┬─ 保留 13 维
           ├─ 合并 2 维（cg+sg → aperture）
           ├─ 重构 2 维（tip_pos+body_pos → place+body，数量不变）
           └─ 新增 1 维（larynx_height）
=  新 16 维
```

### 10.3 修复的 v8 缺陷

| v8 缺陷 | 新方案修复 |
|---------|-----------|
| 部位跨轴且权重悬殊（tip 1.1 vs body 2.7），链步距 12.5× 不均 | place 单轴等距（0.07 步），构造性均匀 |
| 龈齶 ɕʑ 与龈后 ʃ 仅差 0.02（body_pos=0 缺陷） | place 0.430 vs 0.360，构造性分开 |
| 协同发音坍缩（ɧ/tʲ/kʷ 双收缩无法表达） | **body 次收缩轴**：ɧ=(0.360,+0.4)、tʲ=(0.290,+0.4) |
| 部位轴 [0,1] 满铺，协同发音越界无处编码 | **place [0.08,0.92] 留余量** |
| 喉部 k/k͈/k͉ 无法分离 | **glottal_tension 正交轴**（韩语四向分离） |
| F4 及全谱缩放无映射 | **larynx_height 新增** |
| 元音锚点手拍 | 声学数据派生（L&M + phonTools 九语料） |
| 元音圆唇对位置不一致 | 圆唇对共享位置，差异全在 lips_rounded |

### 10.4 继承 v8 的正确设计

- 除阻类型 → 物理效应映射（duration/vel_open/lateral_ratio），不造轴
- airstream 四类 → metadata + airflow_direction
- 时长/鼻化/边音/咝音各自独立轴
- 混淆数据只拟合权重，不定义锚点
