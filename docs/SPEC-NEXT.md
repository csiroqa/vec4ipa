# SPEC‑NEXT：等距部位轴 + 三腔重构（16 → 13 维）设计草案

> **状态：DRAFT v0.1 — 设计讨论稿，未实施。** 本文件不改变任何代码、向量表或度量文件；
> 所有数值为草案锚点，最终值由拟合流程（`tools/fit_metric.py`）决定。
> 目标版本号：`metric.json` version 10（现为 9）。

## 1. 动机与目标

现有 16 维方案（`docs/SPEC.md` v8）的 IPA 解析与往返重建质量良好，但存在三处结构性问题：

1. **部位编码跨轴且权重悬殊，导致部位链"前挤后松"。** 部位被拆在 `tongue_tip_pos`
   （权重 1.1）与 `tongue_body_pos`（权重 2.7）两根轴上，实测擦音部位步距
   （按 v8 `metric.json`）：

   ```
   ɸ→f  0.861   f→θ  1.370   θ→s  1.684   s→ʃ  0.819
   ʃ→ɕ  0.247 ← 龈齶≈龈后，几乎碰撞    ɕ→ʂ  0.678
   ʂ→ç  2.311   ç→x  2.491   ʜ→h  3.082
   ```

   最大/最小步距比 ≈ **12.5×**。全表最近邻：`ɐ~ɜ 0.215`、`ɘ~ə 0.227`、
   `t͡ʃ~t͡ɕ 0.238`、`ʒ~ʑ 0.247`。

2. **龈齶编码缺陷。** `/ɕ//ʑ/` 的生理定义是"龈后收缩 + 舌体抬向硬腭"，但 v8 表中
   它们 `tongue_body_pos = 0.0`（与 `/ʃ/` 相同），仅靠 `jet_focus`/圆唇 0.02 的
   差异区分。

3. **喉部三轴共线冗余。** `voiced`/`constricted_glottis`/`spread_glottis` 在
   16 辅音混淆数据中完全共线（METRIC.md v8 已记载），只能识别三者之和；
   `laryngeal_tension` 在数据中无信号。四轴的实际可识别参数 ≈ 1–2。

**目标（用户需求）：**

- 双脣→脣齒→齒→齒齦→齦後→齦齶→捲舌→硬齶→軟齶→小舌→咽→會厭→喉，全链擦音
  **平等而准确**地支持；
- 肺部气流方式（鼻/爆/塞擦/擦/近/顫/閃/邊擦/邊近/邊閃）、协同调音（ɕʑ ɧ ʍ w ɥ ɫ
  k͡p ɡ͡b ŋ͡m）、非肺气流（喌/内爆/喷）不受影响；
- 音节性、送气、除阻、发声态、调音、协同调音、长短等修饰符全部平等支持；
- **共鸣腔显式化**：口腔腔 / 鼻腔腔 / 咽喉腔 各自为独立维度；
- **分布合理**：部位步距均匀、无近碰撞、混淆拟合与往返重建不劣化。

## 2. 新维度方案（13 维）

| # | 维度 | 语义 | 范围 | v8 替代 |
|---|------|------|------|---------|
| 0 | `place` 部位轴 | 主收缩位置沿声道，双脣 → 喉 | 0.00 = 双脣，1.00 = 喉；13 锚点等距（步距 1/12） | `tongue_tip_pos` + `tongue_body_pos` |
| 1 | `lips_closed` | 唇闭合度（**仅双脣闭合**） | 0 = 开，1 = 双脣全闭 | 保留（语义收窄） |
| 2 | `lips_rounded` | 唇圆展 | −1 = 展 (/i/)，0 = 中性，+1 = 圆 (/u/) | 保留 |
| 3 | `tip_shape` 舌尖形态 | 舌尖/舌叶姿态与高度 | 0.25 静息，0.5 齿擦，0.6 舌叶，0.65 舌尖，0.8 卷舌，1.0 闭合 | `tongue_tip_height` |
| 4 | `tongue_root` **咽喉腔** | 舌根位置（ATR ↔ RTR），咽腔宽度 | −1 = 前伸（扩咽），0 = 中性，+1 = 后缩（咽化） | 保留，权重上调 |
| 5 | `vel_open` **鼻腔腔** | 软腭口鼻通道（鼻化） | 0 = 口，0.6 = 鼻化元音，1 = 全鼻 | 保留 |
| 6 | `lateral_ratio` | 边音气流比例 | 0 = 中央，1 = 全边 | 保留 |
| 7 | `voiced` | 声带振动 | 0 = 清，1 = 浊 | 保留 |
| 8 | `glottal_state` 声门态 | 声门开合（有符号，+ 展开 / − 收窄） | 见 §4 锚点表 | `constricted_glottis` + `spread_glottis` + `laryngeal_tension` |
| 9 | `duration` | 相对时长 | 0 = 爆破瞬音 … 2.0 = 长元音 | 保留 |
| 10 | `jet_focus` | 咝音气流聚焦（谱峰） | 0 = 非咝音，0.8–1.0 = 咝音 | 保留 |
| 11 | `effective_oral_area` **口腔腔** | 口腔最小截面积（元音高度 = 辅音收窄度） | 0 = 全闭 … 1 = 全开 | 保留 |
| 12 | `airflow_direction` | 气流方向 | +1 外呼 / −1 内吸（端点） | 保留 |

**净变化：16 → 13 维（−3）。** 合并三处：`tip_pos`+`body_pos` → `place`（−1）；
`cg`+`sg`+`laryngeal_tension` → `glottal_state`（−2）。

## 3. 等距部位轴 `place`（核心设计）

13 锚点，步距恒为 **1/12 ≈ 0.0833**，任意相邻部位对的距离贡献恒为
`w_place × (1/12)²` —— 从构造上保证"平等支持"，不再依赖拟合碰运气。

| 部位 | `place` | 擦音 | 其他主辅音 | 元音 |
|------|---------|------|-----------|------|
| 双脣 | 0.000 | ɸ β | p b m ʙ ɓ ʘ ⱱ̄* | — |
| 脣齒 | 0.083 | f v | ⱱ ɱ | — |
| 齒 | 0.167 | θ ð | t̪ d̪ n̪ | — |
| 齒齦 | 0.250 | s z | t d n ɹ r ɾ l ɺ ɬ ɮ ǀ ǁ | — |
| 齦後 | 0.333 | ʃ ʒ | t͡ʃ d͡ʒ ǃ | — |
| 齦齶 | 0.417 | ɕ ʑ | t͡ɕ d͡ʑ | — |
| 捲舌 | 0.500 | ʂ ʐ | ʈ ɖ ɳ ɻ ɽ ɭ | — |
| 硬齶 | 0.583 | ç ʝ | c ɟ ɲ ʎ j ǂ | 前（i y e ø ɛ œ æ 等） |
| 軟齶 | 0.667 | x ɣ | k ɡ ŋ ɰ ʟ | 后（u ʊ o ɔ ɑ ɒ ɯ ɤ 等） |
| 小舌 | 0.750 | χ ʁ | q ɢ ɴ ʀ | — |
| 咽 | 0.833 | ħ ʕ | — | — |
| 會厭 | 0.917 | ʜ ʢ | — | — |
| 喉 | 1.000 | h ɦ | ʔ | — |

**设计决定：**

- **元音前后度复用同一轴**（三等锚点）：前 = 0.583（与 ç 同区），央 = 0.500，
  后 = 0.667（与 x 同区）；中元音（ɪ ʊ ɨ ʉ 等）取中间值。元音与同位辅音的区分
  靠 `effective_oral_area` + `duration`，与 v8 中 `/i/` 与 `/ç/` 同用
  `tongue_body_pos=1.0` 的逻辑一致。
- **双重收缩段（协同调音）**：`place` = **后收缩部位**，唇侧收缩由 `lips_closed`
  承载。例：`k͡p` = place 0.667 + lips_closed 1.0；`ŋ͡m` = 同上 + vel_open 1.0；
  `w/ʍ` = place 0.667 + lips_rounded 1.0（软腭为主收缩）；`ɥ` = place 0.583 +
  lips_rounded 1.0；`ɧ`（齦後-齶 双收缩、无唇侧）取中间值 place **0.375**。
  这样 k͡p 与 p（0.000, 1.0）距 `w_place×0.667²`、与 k（0.667, 0.0）距
  `w_lips×1.0²`，与 t（0.250, 0.0）双差，三向均可辨。
- **喌**：ʘ 0.000，ǀ/ǁ 0.250，ǃ 0.333，ǂ 0.583；与气流方向 −1.0 及 λ 联合区分。
- **唇齿 f/v 不再需要 lips_closed=1.0**（v8 中用它强行区分双脣擦音与脣齒擦音，
  是本方案消除的语义混用）：`lips_closed` 收窄为"双脣闭合"，ɸβ 取 0.3（近闭），
  f v 取 0.0。

## 4. 喉部合并：`voiced` + `glottal_state`

`glottal_state` 为有符号单轴（+ 外展 / − 收窄），替换 v8 的
`constricted_glottis` + `spread_glottis` + `laryngeal_tension`：

| `glottal_state` | 含义 | v8 对应（cg, sg, tension） |
|-----------------|------|---------------------------|
| +1.0 | 最大外展 /h/ | (0, 1.0, 0) |
| +0.9 | 清送气 pʰ | (0, 0.9, 0) |
| +0.7 | 浊送气 bʱ | (0.2, 0.7, 0) |
| +0.55 | 气化/弛化 a̤ ɦ | (0.2, 0.55, −0.6) |
| +0.4 | 清不送气 p s | (0, 0.4, 0) |
| 0.0 | 常态（浊段默认） b d a | (0.2, 0, 0) |
| −0.55 | 内爆收窄 ɓ ɗ | (0.55, 0, 0) |
| −0.7 | 嘎裂 a̰ | (0.7, 0, +0.7) |
| −1.0 | 全闭：/ʔ/、喷音持阻 pʼ | (1.0, 0, +0.6) |

**要点：**

- 清浊由 `voiced` 承载；送气/气化/嘎裂/挤喉由 `glottal_state` 承载。四种发声态
  （清、浊、气化、嘎裂）+ 送气三档（0.4 / 0.7 / 0.9）全部可表达，无一丢失。
- 合并依据（METRIC.md v8 已证）：16 辅音混淆数据中三轴完全共线，只可识别
  组合距离；`laryngeal_tension` 无信号。损失的是张力轴的"独立物理证据"
  （EMG），但张力变化在知觉层面恰好体现为收窄量（OQ），故 `−0.55/−0.7/−1.0`
  三档保留了全部可观察对比。
- 原"常态浊 = cg 0.2"改为 0.0：`voiced=1` 已单独表达振动，声门态对浊段默认
  中性，语义更干净。

## 9. 风险与取舍

- **元音前后度粒度**：单轴三等锚点（前/央/后 + 中间值）比 v8 连续轴略粗；
  若需更细可加半档（前偏央 / 央偏后），不破坏等距性。
- **双重收缩段**：k͡p 类取"后收缩部位"，与真正的单收缩软腭音 k 仅差
  `lips_closed` —— 距离由拟合权重保证（预期 ≥ 1.0）。
- **喉部合并的信息损失**：理论上是"可识别参数的合并"，但 `laryngeal_tension`
  在挤喉/嘎裂上的 EMG 独立证据被并入 `glottal_state` 收窄档；如需保留可在
  文档中注明该轴为 EMG 记录值而非知觉量。
- **破坏性变更**：所有二进制（ipa2vec.exe 等）、C 头、UI 与测试均需同步，
  `metric.json` 版本号 9 → 10，向量格式不可与 v8 混用。
