> `docs/FITTING-CORPUS.md` §7（哪些轴不可辨识）、
> `docs/DERIVATION.md`（管道物理与声学通道）、

## 0. 判据

"优雅而高度总括"如果不落到可检验的条件上，只是偏好。**四道判据**：

| # | 判据 | 检验方式 |
|---|------|---------|
| **J1** | 每根轴是一个**独立的几何或时间自由度**，不兼任两职 | 音类区间必须**不重叠**（`body` 就是因为重叠而失败） |
| **J2** | 每根轴在真实语料上有**≥2 个**承载音素 | `tools/audit_axis_coverage.py` 的 `n_off_modal` |
| **J3** | 每根轴的声学通道**唯一且可写** | 归到 `A` 的一根列，通道不得与别的轴共用 |
| **J4** | 能由物理**导出**的量不作为轴存储 | 否则就是冗余（如 `jet_focus`） |

现有 16 维的失败点，逐条对应：

| 现状 | 违反 | 证据 |
|------|------|------|
| `body` 兼任元音前后度 + 次收缩位置 + 协同调音 | J1 | 元音[−0.40,+0.40] 与辅音[−0.48,+0.40] 完全交织 |
| `lateral_ratio` | J2 | Phatak-16 上方差 **0.00000**，权重无数据支撑 |
| `glottal_aperture` ↔ `glottal_tension` 共通道 | J3 | 二者都只走声门源频谱倾斜 |
| `glottal_aperture` 完全决定 `voiced` | J3 | 133 行上 6 个取值恰好二分清浊 |
| `jet_focus` 近似是 place 的函数 | J4 | 咝音按部位排序 0.95/0.90/0.85/0.80 |
| `lips_closed` 与 `tip_shape` 都是"闭合度" | J1 | 同一个自由度拆成两轴 |
| `vel_open` 与 `lateral_ratio` 都是"并联声路" | J1 | 同一个拓扑事实拆成两轴 |

## 1. 核心论断

**声道最多容纳两个重要收缩。** 每个收缩 = (位置, 程度)。这是几何上限，不是建模偏好。
侧支路（鼻、侧流）是**并联通路**，不是第三个收缩。
声源提供**类型**（周期/非周期）与**幅度**（频谱倾斜）两件事，加上一个全局标度（声道长度）。

于是整个发音动作空间是：

```
(主收缩位置, 主收缩程度) × (次收缩位置, 次收缩程度) × 并联通路
× {元音高度, 元音前后} × {周期性, 源倾斜} × 全局标度 × 时长
```

这是 **6 + 2 + 2 + 1 + 1 = 12** 个自由度。其中元音高度/前后只在无局部收缩的音段有意义，
与收缩参数**互斥**（不是重叠），所以判定 J1 成立。

## 2. 12 → 11：哪一根并掉了

**元音高度 `vowel_height` 与主收缩程度 `c1_degree` 并成一轴**，理由是它们是
**同一个量的两个区间**，不是两个自由度：辅音在闭合端（元音在开放端）。审计已实测
`effective_oral_area` 的音类区间**不重叠**（元音 [+0.35,+1.00] vs 辅音 [+0.00,+0.30]），
说明这个并轴是**数据支持**的，而不是权宜。

于是：

### 声道几何（6）

| 轴 | 语义 | 取代 |
|---|---|---|
| `c1_pos` | 主收缩位置，13 锚点等距链，两端各留 0.1 余量 | `place` |
| `c1_degree` | 主收缩紧度：0 = 全开（元音）/ 咝音 → 1 = 完全闭合 | `lips_closed` + `tip_shape` + `effective_oral_area` |
| `c2_pos` | 次收缩位置：−1 软腭 ← 0 无 → +1 硬腭（可外扩至唇） | `body` 的协同调音部分 |
| `c2_degree` | 次收缩紧度。**圆唇在此**（次收缩在唇位） | `lips_rounded` + `body` 的圆唇偏移 |
| `branch_open` | 并联通路导通度：0 = 全口腔 → 1 = 全鼻腔 | `vel_open` + `lateral_ratio` |
| `tract_length` | 声道总长，**所有共振峰按 1/L 整体缩放** | `larynx_height` |

### 元音空间（2）

| 轴 | 语义 | 取代 |
|---|---|---|
| `vowel_height` | F1 开口度 | `effective_oral_area` 的元音段 |
| `vowel_backness` | F2 前后度 | `body` 的元音段（F1/F2 派生，`EXPLORE.md` §7.2 已算） |

### 声源（2）

| 轴 | 语义 | 取代 |
|---|---|---|
| `periodic` | **类型**：0 非周期 / 1 周期。**不是幅度** | `voiced` |
| `source_tilt` | 声门源频谱倾斜（松 ↔ 紧） | `glottal_aperture` + `glottal_tension` |

### 时序（1）

| 轴 | 语义 | 取代 |
|---|---|---|
| `duration` | 段时长 | `duration`（不变） |

### 元数据（不再是距离轴）

| 项 | 处置 |
|---|---|
| 气流机制 | `airflow_direction` 降为标签，λ 罚分承担（现状已是权重 1 + λ） |
| 声调 | 超音段独立系统 |
| 咽化 `ˤ` 的纯元音舌根位移 | **见 §5 的损失清单** |

## 3. 导出量（不存储，由 `A` 计算）

J4 要求能推导的量不做轴：

| 导出量 | 由什么决定 | 取代 |
|--------|-----------|------|
| `jet_focus` / 噪声谱峰频率 | (c1_pos, c1_degree) 经射流噪声关系 | `jet_focus` |
| 爆破谱重心、VOT | (c1_pos, c1_degree, periodic) | 无（原隐含） |
| 鼻腔零点频率 | `branch_open` × 解剖常数 | 原隐含 |
| F1/F2/F3/F4 | 全部几何轴经管道模型 | 原本就要在声学层算 |

## 4. 关键性质（推导，非偏好）

**4.1 协同调音现在是链上的位置，不再是符号翻转。**
`ʲ` = c2_pos +1；`ˠ` = c2_pos −1；`ˤ` = c2_pos −0.5（次收缩在咽）。
三者是同一条链上的点，与 `c1_pos` 的锚点语义一致，**共用同一套偏移机制**。

**4.2 三重调音不再需要链条弯折。**
软腭化 + 腭化 + 唇化 = (c1_pos = 软腭, c2_pos = 硬腭, c2_degree = 唇缩)。
三个独立参数。

**4.3 `periodic` 是类型，因此度量对它必须非线性。**
0/1 跃迁：几个百分点的周期调制即可检出，`D² = w·Δ²` 对它结构性失配
（`docs/DERIVATION.md` §6）。修正走"独立距离项 + 平坦惩罚"，不走权重。

**4.4 `tract_length` 在声学层近似正交于其他所有轴。**
它改变 L 本身，`f_n ∝ 1/L`，其 `A` 列 ∝ (F1,F2,F3,F4) 向量。这是
"Phatak 上方差恰为 0"的物理解释。

**4.5 `source_tilt` 合并了审计与推导共同指认的那一对。**
`glottal_aperture`/`glottal_tension` 只走同一条通道（源频谱倾斜），
且前者完全决定后者所在的清浊。合并后该共线性问题**从定义上消失**。

## 5. 诚实的损失清单

重设计不是白拿的。以下三项是**明确丢失**的，必须写进规格而不是藏起来：

| 损失 | 说明 | 是否可接受 |
|------|------|-----------|
| **L1 纯 ATR/RTR 元音** | 阿拉伯语的 ɪ/ʏ、a/ɑ 是舌根位移，无任何收缩。声学上等价于 F1/F2 平移，可由 `vowel_height`/`vowel_backness` **近似**表达，残差未建模 | 可接受，须在规格里声明这是二阶近似 |
| **L2 ɕ/ʃ 谱峰逆序** | `jet_focus` 按部位排序，但 ɕ(0.90) > ʃ(0.85) 与部位序相反（中文 ɕ 谱峰本就高于英语 ʃ）。改为导出量后**这个反常会丢失** | 不可接受 → 见 §6 闸门 C |
| **L3 声学通道的可分离性下降** | 12 自由度的声学层秩可能 < 11，使某些轴再次不可辨识 | 必须由 §6 闸门 B 量化 |

**L2 是这份提案最脆弱的地方**，下面单独处理。

## 6. 实施前的三道闸门

### 闸门 A：映射规则必须先写成纯函数

把现有 133 行按显式规则映射进新 11 维（规则来自 `verify_modifiers.py` 的
`MODS` 与 `spec_next.scheme`），产出 `vec_table_11.json`。**不改 C 运行时。**
判据：133 行全部有映射，无一行落到"无对应"。

### 闸门 B：秩与可辨识性

对新 11 维跑一遍 `tools/audit_axis_coverage.py`（把 `dims` 换掉即可）。
判据：**每根轴 `n_off_modal ≥ 2`**，即 J2 在 112 个语料音素上成立。
若某轴 < 2，说明它仍然被其他轴吸收 → 回炉。

### 闸门 C：咝音谱峰必须保住

L2 的解法有两条，都要在闸门里试：
- **C1**：`jet_focus` 不做导出量，保留为一根"咝音谱峰序"轴（但它违反 J4，
  是已知妥协，须显式记录）
- **C2**：让导出关系带一个部位修正项 `δ(c1_pos)`，使谱峰不是 place 的严格函数
  （物理上正确：谱峰由沟槽几何决定，而沟槽在齶化部位最深）

判据：`d(ɕ, ʃ)` 在新表里仍显著大于 `d(ɕ, ɕ)` 之外的相邻咝音步长，
即 ɕ/ʃ 的倒序不可被平滑掉。

### 闸门 D：LOCO 不劣化

用 `tools/fit_metric16.py` 的流程在 11 维上重拟合，跑 Phatak LOCO。
**判据：新 LOCO ≤ 旧值 22,355 + 5%**（约 23,473）。

`EXPLORE.md` 的先例是 13→12 维代价 +0.6%。5% 是本提案自己定的容忍带，
**判据先写死，跑完不许改**。
