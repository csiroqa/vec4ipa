# 声学层推导：M_phys = Aᵀ W_a A

> 2026-08-09。承接 `docs/FITTING-CORPUS.md` §7 的审计结论。
> **本文不含实现改动。** 目的是给出可证伪的推导，而不是又一套说法。
> 每条断言标注三类之一：**推导**（由写出的关系得出）、**标定**（需要数据定一个常数）、
> **预测**（与当前权重冲突，可检验）。

## 1. 为什么必须走物理

审计已给出硬约束（`docs/FITTING-CORPUS.md` §7.4）：

```
larynx_height    : kʼ pʼ qʼ tʼ t͡ʃʼ ɓ ɗ       7 个音素
glottal_tension  : kʼ pʼ qʼ tʼ t͡ʃʼ ɦ ʔ       7 个音素
```

整个 IPA 空间里携带这两根轴的就是这 7 个音素。**语料的上限是 7，不是"还没找到"。**
统计拟合对这 6 个样本的方差 → 权重，无解。剩下的合法路径只有两条：物理，或承认它
是约定。

## 2. 数学骨架

三层分开，各自有独立的合法来源：

```
生理层 p (16维, 现有表)
   │  A = ∂(声学参数) / ∂(生理轴)     —— 管道物理，闭式可导
   ▼
声学层 a (F1 F2 F3 F4 / 零点 / HNR / 频谱倾斜 / 噪声谱峰 / 鼻化阻抗)
   │  W_a = 对角听觉敏感度            —— 临界带宽（物理）+ MN55 层级（人）
   ▼
知觉层：M_phys = Aᵀ W_a A
```

**推导**：若 `a = A·p`（线性化），且知觉距离由声学距离决定且权重对角，则

$$D^2(p, p') = (A\,\Delta p)^\top W_a (A\,\Delta p) = \Delta p^\top \underbrace{A^\top W_a A}_{M_{\text{phys}}} \Delta p$$

于是 `M_phys` 不再是 16 个自由数，而是 `A` 与 `W_a` 的乘积。
**关键性质（推导）**：`rank(M_phys) = rank(W_a^{1/2} A) ≤ min(16, 声学参数个数)`。
若某组轴在声学层投影后共线，它们在知觉层就**不可能**被分开——与语料多少无关。

## 3. A：逐轴的管道物理

管道共振 f_n ∝ 1/L（推导）。对一个带收缩的管：

| 生理轴 | 几何作用 | 声学后果 | 类别 |
|--------|---------|---------|------|
| `place` | 前腔长度 L_f = x | f_n ∝ 1/L_f，**F2/F3 为主** | 推导 |
| `body` | 后腔 / 第二收缩 | F1、F2 | 推导 |
| `lips_closed` | 前端封闭 → L_f→0 | F1 极高 / 共振消失 | 推导 |
| `lips_rounded` | 前端 +ΔL ≈ 1–2 cm | **F1、F2 同降，F2 降得更多（Hz）** | 推导 + 标定 ΔL |
| `tip_shape` | 收缩在齿后 ↔ 邮音区 | **F2/F3 交叉**（卷舌 F2 低于齿音） | 推导 |
| `tongue_root` | 咽腔收缩 → 低频零点 | F1/F2 下移（RTR） | 推导 |
| `vel_open` | 侧支路 → 零点 | **零点远低于任何共振峰**；鼻音 F1 被毁 | 推导 |
| `lateral_ratio` | 另一条侧支路 | 与 `vel_open` 同机制 | 预测（列应高度相关） |
| `voiced` | 声源由非周期变周期 | **范畴跃迁**（见 §6） | 推导 |
| `glottal_aperture` | 声门开合 → 源频谱倾斜 | 频谱倾斜 + HNR | 推导 |
| `glottal_tension` | 声门张力 → 源倾斜 | **同一条通道** → 与上列近乎平行 | 预测 |
| `larynx_height` | **总长 L** | **f_n ∝ 1/L：全谱等比缩放** | 推导 |
| `duration` | 时间 | 谱包络，非稳态 | 推导 |
| `jet_focus` | 沟槽几何 → 湍流噪声谱 | 谱峰频率 | 推导 |
| `effective_oral_area` | 收缩截面积 | F1 + 湍流阈值 | 推导 |
| `airflow_direction` | 流向 | **无稳态声学签名** | 推导 |

**`larynx_height` 那一行是本节的核心（推导）**：它改变的是 **L 本身**，所以它的
`A` 列 ∝ (F1, F2, F3, F4, …) 向量——**与 f_n 成正比的同一个向量**。其余各列
在共振峰空间里的形状各不相同（`place` 主要打在 F2/F3，`body` 在 F1/F2，
`lips_rounded` 在 F1/F2）。因此：

> **P1（预测）**：`larynx_height` 与所有其他轴在声学层近似正交。
> 它的权重不可能靠"哪些轴一起变大"从数据里学出来——这与审计发现的
> "Phatak-16 上方差恰为 0" 是同一件事的两种说法。

## 4. W_a：听觉敏感度

**推导**：临界带宽随频率增长（Terhardt），CB(f) = 25 + 75(1 + 1.4(f/1000)²)^0.69 Hz。
频率分辨率 ∝ 1/CB：

| f | 250 Hz | 500 Hz | 1 kHz | 2 kHz | 4 kHz |
|---|-------:|-------:|------:|------:|------:|
| CB (Hz) | ~104 | ~117 | ~163 | ~309 | ~710 |
| 相对敏感度 | 1.00 | 0.89 | 0.64 | 0.34 | 0.15 |

**同一 Hz 的差异，在 250 Hz 附近比在 4 kHz 附近重要约 7 倍。**

再叠加 **MN55 层级**（`METRIC.md` §2，真人掩蔽听辨，L0 级数据）：浊音 tier 8、
部位 tier 1。这两条合起来给出 `W_a` 对角：

| 轴 | 作用的频带（推导） | 敏感度（推导） |
|----|------------------|--------------|
| `vel_open` | 零点，**远低于任何共振峰** | 高（最低频带） |
| `lateral_ratio` | 支路零点，同类 | 高 |
| `effective_oral_area` | F1（~300–800 Hz） | 高 |
| `tongue_root` | F1/F2 | 高 |
| `lips_rounded` | F1/F2 | 高 |
| `place` | F2/F3（1–2.5 kHz） | 中 |
| `tip_shape` | F2/F3 交叉 | 中 |
| `body` | F1/F2 | 中高 |
| `larynx_height` | 全谱缩放 | 取决于整体听感（见 §6） |
| `glottal_aperture` / `glottal_tension` | 源倾斜（全带，但差异显现在高频） | 中 |
| `jet_focus` | **噪声谱峰 2.5–5 kHz**（Jongman 2000，本仓已引） | **低** |

## 5. 推导与当前权重的对撞

当前权重（`tools/data/spec_next.scheme:18`，运行时权威）：

```
place 30  body 15  lips_closed 0.5  lips_rounded 8  tip_shape 4  tongue_root 2
vel_open 6.7  lateral_ratio 1  voiced 2  glottal_aperture 1.1
glottal_tension 1  larynx_height 6  duration 5  jet_focus 8
effective_oral_area 16  airflow_direction 1
```

四条对撞：

### C1 `jet_focus` = 8，但推导说它作用在最不敏感的频带

噪声谱峰 2.5–5 kHz，CB 309–710 Hz，敏感度 0.15–0.34 —— 全表最低。
当前 8.0 却与 `lips_rounded`(8，低频带，敏感度 ~0.9) **持平**，
并是 `vel_open`(6.7，最低音带) 的 1.2 倍。

> **P2（预测）**：推导给出的 `jet_focus` 有效权重应显著低于 8，
> 大概率落在 `lateral_ratio` / `airflow` 那一档（~1）。
> 这是 §4 里最干净的一条可证伪预测：**只要把 CB 加权算出来，排序就定了。**

### C2 `voiced` = 2，但 MN55 层级给的是 8，且它是范畴跃迁

`fit_metric16.py:35` 自己把 tier 8 映射到 `voiced`/`glottal_aperture`/
`glottal_tension`，但拟合结果是 voiced 2.0 + aperture 1.1 = 3.1。
拟合数据把这个先验**往下压了 2.6 倍**。

> **P3（预测）**：要么 Phatak 数据否定了 MN55 的层级（那要给出机制），
> 要么当前是 `place`=30 在支配似然、把浊音挤掉了。

### C3 `glottal_aperture` 与 `glottal_tension` 在 A 中近乎平行

两者都只通过**声门源频谱倾斜**进入声学层。这意味着它们的 `A` 列近似共线，
`M_phys` 里两轴的耦合项会很大。

> **P4（预测）**：`Aᵀ W_a A` 会显示这两轴近乎不可分离。
> 诚实的结论是**合并成一轴、给两个载荷**，而不是假装正交。
> 这与审计 §7.3 的发现互相印证：`glottal_aperture` 在 133 行上完全决定 `voiced`，
> 同一族共线性问题。

### C4 `lips_closed` = 0.5 是全表最小，但它是双唇闭合

双唇闭合把前腔封死，是全表最大的声学事件之一（§3）。它拿到 0.5 的合理解释是
**冗余**：`place` 已经把 p/t/k 分开了，所以拟合不需要闭合这个线索。

> **P5（预测）**：这是正确的**条件**权重，不是绝对权重。若 `place` 权重变化，
> `lips_closed` 应跟着变——否则说明它被冗余吸收后失去了独立性。
> 可检验：在去掉 `place` 的子空间上重拟合，`lips_closed` 应显著上升。

## 6. 推导给出的最重要一条：若干轴不是连续微扰

**推导**：`f_n = c/(4L)` 是**一阶**关系，对 `place`/`lips_rounded`/`larynx_height`
这类改变 **L** 的参数，∂f/∂参数 有限且光滑，线性化成立。

但下列轴不是"同一构型的微调"，而是**构型类型的变化**：

| 轴 | 变化内容 | 为什么线性化失效 |
|---|---------|----------------|
| `voiced` | 声源由非周期 → 周期 | 感知门限处导数奇异；数个百分点的周期调制即可检出 |
| `vel_open` 0↔1 | 声道**断开**、接上侧支路 | 拓扑变化，非连续 |
| `airflow_direction` | 流向反转 | 无稳态谱，度量只能走 λ 元数据（当前实现已如此，正确） |
| `lips_closed` | 前端封闭 | 前腔长度 → 0，共振消失 |

**推论（推导 + 解释）**：`D² = Σ w_k Δ_k²` 这形式对上述轴是**结构性失配**。
它们不是"权重调小一点"的问题，而是模型形式不对。这解释了为什么
`METRIC.md` §3 记录的那个 rescale 补丁（s² = 1.758，把 voiced/cg/sg 一起乘）
**必须存在**：它是在用缩放去补偿一个本该用非线性处理的效应。

> **P6（预测）**：把 `voiced`/`vel_open`/`lips_closed` 换成非单调的跃迁函数
> （或直接当类别特征 + 独立距离项），同样维度下 Phatak 的 LOCO NLL 会低于
> 22,355。若不降，说明线性形式在此语料上并无代价——那也是有用信息。

## 7. 推导的合法边界

**能推**：每根轴的声学通道、频带、通道之间的共线结构、
`larynx_height` 的全谱缩放性质、类别轴与连续轴的区分。

**不能纯推**：

1. **`W_a` 的绝对刻度。** 临界带宽给的是相对敏感度；"听者多在乎部位还是清浊"
   是耳与脑的属性，不是管的属性。至少需要 MN55 那一层 L0 数据做锚。
2. **跨语言音系归一化。** 同样的 F2 在不同语言里权重不同（`EXPLORE.md` §7.2
   已经用语言内极差归一化处理过）。
3. **二阶效应**：F2 过渡轨迹、协同发音补偿、元音空间的学习效应。
4. **耳权重是否各向同性**——§4 假定 W_a 对角。频带间的非对角耦合（masking、
   响度交互）会让它不满秩。
