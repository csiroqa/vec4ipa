# 序列对齐框架（`-A`，设计 B）：四个动作 + 统一时长语义

对齐是段序列上的编辑距离 DP（`run_align`）。每个格子有四个候选动作，
所有代价都来自度量本身，没有手调常数：

| 动作 | 代价 | 说明 |
| ---- | ---- | ---- |
| 替换 1:1 | `seg_subst(a,b)` | 度量 + 气流 + 声调；纯长度对走莫拉费率 |
| 吸收 1:2/2:1 | `absorb_dist(a,b1,b2)` | 点作为相邻两段的协同发音联合体 |
| 元音块 k:m | `seg_block_dist` | 纯元音串（k+m≥3）的轨迹对轨迹比较 |
| 插入/删除 | `seg_indel(x) = d(x, ə)` | 中性元音 ə 为 null 元素 + 声调 |

## 吸收（1:2 / 2:1）

点 `a` 作为 pair `(b1,b2)` 的协同发音联合体：`ã~(a,n)`、`tʰ~(t,h)`、
`kʷ~(k,w)`、`ɛ~(a,i)`。

- **锚定锁**：锚 b1 拥有的维度（`|b1[k]| ≥ 0.3`，`IPA2VEC_ABSORB_TAU`）上
  a 必须匹配 b1；
- **自由维**：a 可取 b1→b2 插值轨迹上的最近点（投影，t* 截断到 [0,1]）；
- **时长例外**：`duration` 是测量轴而不是发音手势，不参与锁与投影；
- **莫拉项**：与元音块 A3 同费率（`IPA2VEC_CONTOUR_MORA = 1.0`）——
  `dm = 点元音时长 − pair 元音成员时长和`，辅音成员贡献 0；
- 声调与**锚点**比较（点实现的是锚——min 会让无调点躲掉锚上的调，
  `ã~(a˥,n)` 必须付调；与块的逐点声调一致），气流差取较差成员
  （min 会让 (ǃ,a)~t 逃过 λ）。

### 八道门（防塌缩，全部来自协同发音公理）

1. **meaningful**：锁定项非零，或未截断投影 t* 严格落在 (0,1)；
2. **非成员**：`seg_dist(a,b1) < 0.5` 或 `< b2` 时拒绝——防 `ka~a`（起点删
   到只剩锚价）；
3. **类门**：点与锚必须同类（元音点 ↔ 元音锚、辅音点 ↔ 辅音锚）——
   [ã] 不可能是 [d] 的修饰形（`ã~(d,ɛ̃)`）；
4. **锚手势门**：`locked > 1.0` 时拒绝（`IPA2VEC_ABSORB_LOCKED`）——点必须
   在**锚自己的手势**上匹配锚：`locked` 是点与锚在锚定维上的 d²。真实吸收
   全部 ≤ 0.28（最大是 tʰ 的送气间隙 d(tʰ,t)²），而不同音位在这里付出
   全部对比——`b~(d,o)` 的 locked = d(b,d)² ≈ 8.8（部位/舌尖全在 d 的锚
   定维上）、`(a,p)~k` ≥ 5（时长/浊音维）。这是"点必须是锚的修饰形"的
   精确形式化；
5. **混合方向门**：协同发音是**混合**——点在锚拥有的每个手势维上必须位于
   锚与对子成员之间（α·β ≤ 0）。向成员反方向移动的修饰不是对子解释的
   （`ã~(ɛː,kʼ)`：鼻元音的口部面积移动背离挤喉塞音）；
6. **用成员门**：点必须在**对子成员自己拥有的手势维**上向成员倾斜
   （α·β < 0）——点必须真正实现成员的内容（ã 在 vel_open 上向 n 倾斜、
   tʰ 在 glottal_aperture 上向 h 倾斜、Cʷ 在 lips_rounded 上向 w 倾斜）。
   只靠共享标量轴（元音高度等）的倾斜不算（`ɛ̃~(ã,d)` 在 oral 轴上居中，
   但 d 拥有的 place/tip/voiced 上毫无倾斜）；
7. **元音门**：点非元音且 pair 含元音 → 拒绝——元音内容只能被元音点吸收。
   `tʰ~(t,o)` 会把 [o] 藏在锚后只付 1 莫拉；真实用例 ã/ɛ 都是元音点，
   Cʰ~(C,h)/Cʷ~(C,w) 的 h/w/j 都不是元音（`seg_is_vowel`）；
8. **成员类门**：元音点只能吸收**可被元音实现**的辅音成员——鼻音
   （vel_open ≥ 0.7）或平滑声道（oral ≥ 0.3：w/j/h/ɦ）；阻塞音成员
   （oral < 0.3 且无鼻音逃逸：塞音/擦音/挤喉/搭嘴/内爆）的闭锁/摩擦内容
   任何元音都实现不了。`ə~(ɛː,kʷ)` 会让中性元音（一切质心）把圆唇化塞音
   藏在"居中"背后——几何无法区分"实现了成员内容"与"恰好居中"，只能按
   成员类别禁掉。**已知限制**：软腭化/咽化元音（aˠ ~ a+ɣ）在门外
   （ɣ/ʕ 有收窄），需要时再放开。

**重音豁免（geminate）**：对子成员完全相同（b1 ≡ b2）时，成员门/用成员
门/meaningful 门豁免——真重音的内容就是**多出的一莫拉**，由时长项计价：
`(m,m)~m` 删一莫拉（1.0）、`mː~(m,m)` 是长度恒等（0），与元音侧
`[aa]~[a]` = 1.0、`aː≡aa` = 0 完全一致（M1 推广到辅音）。`(k,a)~a`
仍被拒（对子不是重音）。**表格限制**：塞音 duration = 0（`tː≡t`），
所以 `(k,k)~k` = 0——重音塞音的莫拉在数据里不存在，对齐如实反映。

## 交叉公理与审计（cross-cutting design）

公理**一次陈述、逐动作检查**——不枚举用例，任何路径都不许破坏：

| 公理 | 内容 | 1:1 | 吸收 | 块 | indel | 状态 |
| ---- | ---- | --- | ---- | -- | ----- | ---- |
| M0 | 代价全来自度量，共享费率（莫拉 1.0、λ、TAU、LOCKED） | ✓ | ✓ | ✓ | ✓ | 成立 |
| M1 | 同一"一莫拉"差在所有路径同价 | 纯长度对走莫拉费率 | ✓（含重音豁免） | ✓ | duration 分量走莫拉费率 | 已修（seg_subst + geminate + seg_indel） |
| M2 | 声调沿对应逐点计价，不因路径消失 | 直接 | 锚点 + 对子 | 逐点 + 多余成员 | +1/调 | 已修（吸收锚点单边；块的(1,m)多余成员调、吸收对子成员的调都按存在计 +1） |
| M3 | 气流类差不因路径消失 | 直接 | 劣侧 | λ | 含在度量 | 成立 |
| M4 | 吸收许可：八道门 | — | ✓ | — | — | 成立 |
| M5 | 块只压缩全元音串，A1-A4 | — | — | ✓ | — | 成立 |
| M6 | 对称 d(A,B)=d(B,A) | ✓ | ✓ | ✓ | ✓ | 模糊零违例 |
| M7 | 恒等 d(A,A)=0 | ✓ | ✓ | ✓ | ✓ | 模糊 60/60 |

**M1（已修，全路径闭合）**：纯长度对——仅 duration 不同的 1:1 替换
（`aː~a`）——按 A3 莫拉费率计价（`seg_subst`），与 `aa~a`（块）和
`aː≡aa`（吸收恒等）同价：`aː~a` = `aa~a` = 1.0，恒等 0，三角闭包成立。
推广到辅音重音（重音豁免）与 indel（`seg_indel` 的 duration 分量走莫拉
费率：删 `aː` 比删 `a` 多恰一莫拉，D² 差 = 1.0）。度量的 duration 权重
5 保留为向量空间的身份权重（最近基、`-d`、混合替换不变）。研究记录：曾试
过把权重 5→1.0（对齐 8 个钉值偏移、度量空间 3 个最近基回归：β̃→m——鼻化
擦音的 vel 0.6 恰好卡在 β(0) 与 m(1.0) 之间，只有 w_dur ≥ 3.7 才保持 β，
而混淆拟合值 1.405 同样翻车，该钉值从来只由手调 5 支撑）；5→1.0 也试过
（M1 仍差 0.185）。结论：M1 的干净解法只存在于对齐内部（长度对、重音、
indel 按莫拉计），不动度量。

## 验证（property-based，非逐例）

`python tools/validate_alignment.py [N] [exe]` — 随机字符串对上的**不变量**
模糊：M1（元音与辅音重音的一莫拉一致性）、M6 对称、M7 恒等、M4 许可
（解析 `-A` 输出，断言没有任何
"辅音点吸元音成员"或"元音点吸阻塞音成员"的吸收行）。曾抓到逐例测试
无法覆盖的漏洞：`ãiɓ~iɛːkʼã` 中 `ã~(ɛː,kʼ)`、`ã~(aʲ,k)`、`ə~(ɛː,kʷ)` 等
（本表第 3/5/6/8 道门由此而来）；3000 对宽池模糊当前零违例。

## 元音块（k:m）

两侧全元音串（k+m≥3，每侧 ≤ 8），四条公理：

- **A1 代表**：锚点均值为单位质量位置；
- **A2 跨度包含**：子轨迹（跨度被包含）不付 reach，只付跨度间隙；
- **A3 莫拉**：时长和之差，每莫拉 1.0 距离单位（软费率；度量自身权重 5
  会让所有轮廓 ≥ 2.24，压过 /a/~/ɛ/ = 1.26）；
- **A4 倒序**：只罚倒序对应（ai~ia 付费，ai~ɛe 平行滑动免费），近置换时
  按正序点对点计费（aiu~iau 不为零）。

## 统一时长语义（为何只有一档费率）

语音学事实：单化 `ai→ɛː`、鼻化 `VN→Ṽ` 普遍伴随**补偿性延长**，莫拉保持。
因此 1:m 匹配的正确比较对象是**总时长和**，由数据决定，而不是动作类型：

| 比较 | 旧行为 | 新行为 | 语音学 |
| ---- | ------ | ------ | ------ |
| `ɛ~ai`（短单元音对双音） | 1.0057（免莫拉，错） | 1.2560 | 付 1 莫拉 |
| `ɛː~ai`（加长单化） | 0.7599 | 0.7599 | 免莫拉 |
| `ã~an` | 1.1560 | 1.1560 | n 非元音，莫拉中性 |
| `ãː~an` | 2.5172（时长锁误收） | 1.5285 | 2 vs 1，付 1 莫拉 |

实现：吸收不再把 duration 锁进锚定门（旧代码把元音时长 1.0 ≥ 0.3 意外锁
住——这就是"0 费率"的来源：阻塞音时长 0 落在自由侧、元音落在锁侧，同
一规则在两个域里行为相反）；改为统一加 A3 式莫拉项。费率 `1.0/莫拉`，
时长差由表格数据承载（写 `ɛ` 就付费、写 `ɛː` 就免单）。

## 为什么保留两个算子

吸收 = **点到轨迹**（1:m，锚定）；块 = **轨迹对轨迹**（k,m≥2，均值/跨度/
莫拉/倒序）。A1、A4 结构上要求双侧都是轨迹；A3 时长公理已统一为同一个
莫拉项，两算子在一档费率上一致。1:2 元音格两者竞争，DP 取严格更小者。
