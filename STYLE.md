# Style

Generated by `house-style`. Edit freely; project rules override the global ones.

## Resolution

Before editing a file:

1. Match its path and language against the table below.
2. Read the named authority before writing code.
3. If no rule matches, follow the nearest existing file in the same directory.
4. If the language or style is new, stop and ask.
5. Never reformat code outside the current diff.

## Routing

| Path | Authority | Optional check |
|---|---|---|
| `kernel/**/*.[ch]` | Linux Kernel Coding Style | `scripts/checkpatch.pl --strict` |
| `src/**/*.[ch]` | LKCS, user-space | `clang-format --dry-run --Werror` |
| `**/*.ts`, `**/*.tsx` | Google TypeScript Style | ESLint naming rules |
| `**/*.py` | PEP 8 + project | Ruff `N` + format |
| `**/*.go` | Go style | gofmt + revive |
| `**/*.rs` | Rust style | rustfmt + clippy |
| `docs/**/*.md` | Microsoft voice + Google developer docs structure | Vale |
| `openspec/**` | OpenSpec schema + RFC 2119 | `openspec validate --all --strict` |
| `git commit` | Linux kernel `submitting-patches.rst` | `.githooks/commit-msg` |

## Limits

See `limits.yaml`. Hard limits fail; targets warn.

## Git

- Subject: `area: imperative summary`, no period, <=50 chars target (72 hard).
- Body: blank line, wrapped at 72 columns, explains why and what.
- One logical change per commit; each commit builds.
- Never invent `Signed-off-by`, `Reviewed-by`, `Tested-by`, or `Acked-by`.
- Never commit, amend, or force-push unless asked.
